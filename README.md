# Jotify 🎵

**Jotify** is a Flutter music player customized from the open-source BlackHole project.

![Jotify icon](assets/ic_launcher.png)

## Features
- Saavn song search with more initial results and a paginated **View All** screen.
- `Khama Ray Khama` searches additionally check `Khama` and `Khamma` spelling variants.
- Saavn audio playback, library, downloads, playlists and YouTube in-app video player (as supported).
- Custom launcher logo and **Jotify** app display branding.

## Build

The `.github/workflows/import-and-build.yml` workflow (when present in the repository) builds a debug APK using Flutter 3.19.6.
An existing repository can apply updates by uploading `krishna-music-source-ready.zip` to its root and running the import workflow.
